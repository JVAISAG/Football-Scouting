# Resume bullets and portfolio description

## Suggested project title

Football Scouting and Recruitment Decision Support | Python, SQL, scikit-learn, JavaScript

## Resume bullets

- Engineered a reproducible Python/SQL pipeline for **1,313,773 real football events across 380 Premier League matches**, with data-quality checks and a SQLite analytical warehouse.
- Built and chronologically evaluated an original non-penalty xG model on **9,816 shots**, achieving **12.8% lower test log loss** than a constant baseline (0.2878 vs 0.3299).
- Created role-based shortlists for **170 eligible players** and an exact budget-constrained three-player recruitment simulation, delivered through an interactive offline dashboard.

## Short portfolio description

A historical 2015/16 Premier League case study combining event-data engineering, shot conversion modeling, role-aware scouting and constrained recruitment selection. Includes an original xG experiment, chronological train/validation/test splits, match-clustered statistical checks, transparent role scores, sensitivity analysis and an offline dashboard.

## Explain the measured result correctly

The 12.8% improvement refers to **probability error measured by test log loss**, not 12.8% more goals, 12.8 percentage points of accuracy, or proven recruitment value. The scouting refit is separate and descriptive. Recruitment uses hypothetical credits, not real transfer prices.

Use these bullets after reviewing and rerunning the work so you can explain each claim. Replace or shorten the wording to match what you understand and demonstrate.
