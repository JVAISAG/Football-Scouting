# Quick start

1. Open **dashboard.html**. It works offline.
2. Read **reports/FINDINGS.md** for measured results.
3. Read **reports/INTERVIEW_GUIDE.md** to prepare your explanation.
4. Explore **sql/analysis.sql** and **src/** to understand the work.
5. Follow **README.md** to download the pinned source data and rebuild the warehouse.

The ZIP contains code, trained models, aggregate analyses and the offline dashboard. Original event records and the local warehouse are omitted from the ZIP; the source downloader reconstructs them. The working project folder on this computer has the complete processed warehouse.

Recruitment costs are hypothetical. This is a historical 2015/16 Premier League case study.
